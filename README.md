# 传声筒 · 默契挑战

同一个网页里的两款派对小游戏,服务端零依赖。

- **传声筒**(3–8 人):描述接龙,看一句话能歪成什么样。
- **默契挑战**(2–5 人):同时写词,看你们能不能想到一块。

打开页面先在「小游戏桌」选一款游戏,再起名字入座。房间还空着时,第一位入座的人决定本房间玩哪款;房间已经有人时,新来的人加入房间正在玩的游戏。入座后房主仍可在大厅切换。

## 传声筒 · 玩法

1. 所有人入座后开局,系统随机排棒次。
2. **第一棒**想一个词,用一句话描述它(描述里不能出现这个词)。原词只有他知道。
3. **下一位**看到上一棒的描述,猜一个词;再用自己的话描述**自己猜的词**。
4. 依次传递。每个人只看到上一棒交来的那一条描述,看不到更早的历史。
5. **最后一棒**只猜,不再描述。
6. 揭晓完整链路:原词一路漂移到最后变成了什么。如果最后一棒一字不差地猜回了原词(忽略空格、标点、大小写),会触发「完美接龙」印章和礼炮。
7. 全体投票,选出本回合「最猪的人」。
8. 如果开了卧底棒,再投一轮「谁是卧底」:匿名投票,卧底本人不能投。最终页公开真卧底,以及大家有没有猜中。
9. 再来一局,重新随机排序。

每棒限时 **60 秒**(猜词和描述合计)。超时后系统会自动把你已填的内容传下去,没填的部分用占位内容代替,不会卡住整局。

描述提交时会自动检查两件事:

- **不能出现目标词**:第一棒是原词,之后每位玩家是「你正在描述的那个词」(你自己猜出来的答案)。忽略空格和标点。同义词、谐音等仍靠自觉。
- **本棒限制卡必须满足**(开启限制卡时):例如「只能用 5 个字」「必须提到一种动物」。

不通过会被拒绝并提示,计时不会暂停,修改后重新提交即可。超时自动生成的占位描述不参与检查。

## 默契挑战 · 玩法

2–5 人,同一道题同时写词,直到全员想到一块。

1. 在选游戏界面选「默契挑战」,2–5 人入座后点「同时开猜」。
2. 大厅的「指定主题」默认开启:系统给本局一个主题(如「夏天」「便利店」),第一轮所有人凭第一反应写一个词。关掉后本局自由起手,想到什么写什么。
   主题题库在 `data/themes.json`,修改后**下一局生效,不用重启服务**。
3. 每轮 **40 秒**,1–8 个字;**提交前看不到任何人的答案**,提交即锁定。
4. 所有在线玩家都交卷会立刻揭晓,不用等满 40 秒。
5. 看到上一轮所有人的词后,继续写一个「能把大家拉近」的新词。
6. 当所有参与者同一轮写出完全相同的词(忽略空格、标点、大小写),就算相遇成功。
7. 超时会自动沿用自己上一轮的词;第一轮没有旧词,记为「未答」。手动提交不能重复自己上一轮的词。
8. 本局不限轮数,房主可以随时点「结束本局」收场。

结算按用了几轮相遇给出称号,**每一轮的词**都会保留成一条思维轨迹。

| 轮数 | 称号 |
|---|---|
| 1 轮 | 心有灵犀 |
| 2 轮 | 默契十足 |
| 3–4 轮 | 脑回路接近 |
| 5 轮以上 | 终于走到一起 |
| 房主结束 / 人不够 | 各想各的 |

掉线的人本轮弃权,不参与判同;如果揭晓时在线不足 2 人,本局结束。

## 传声筒 · 房主与花样玩法

**第一个入座的人是房主**。房间还空着时,第一位入座的人在选游戏界面选的游戏会成为本房间的游戏。入座后只有房主能切换游戏、开始游戏、勾选玩法、清空牌桌,其他人会看到「等房主开局」。

玩家关闭页面后会先离线,5 分钟内重连可恢复;在大厅超过宽限期会退出牌桌,如果掉线的是房主,房主会顺延给下一位在线玩家。房主也可以在大厅手动「移出离线玩家」。

开局前房主可以打开以下玩法(可多选,可叠加)。这些开关只作用于传声筒;选择默契挑战时大厅会隐藏它们。

- **卧底棒**:随机一名中间玩家成为卧底,只有他自己知道任务——从猜词到描述,悄悄把话带偏。最猪投票后还会有一轮匿名「猜卧底」,卧底本人不能参与;最终页揭晓真卧底和竞猜结果。
- **限制卡**:每位描述者(最后一棒除外)抽一条限制,例如「只能用 5 个字描述」「描述里必须提到一种动物」「用否定句开头」。提交时程序会自动校验。
- **类别词库**:开局随机一个类别(食物、动物、职业……),第一棒只能在该类别里想词。
- **历史记录**:开启后,已经传完自己那一棒的人,在等待时可以回看目前的传递记录;还没轮到的人看不到,避免提前剧透。

## 启动

```bash
node server.js
```

打开 <http://localhost:3000>。换端口:

```bash
PORT=4000 node server.js
```

零依赖,不需要 `npm install`。

调试时可以缩短计时:

```bash
# 传声筒:每棒 5 秒,掉线 2 秒后移出
TURN_SECONDS=5 DISCONNECT_GRACE_MS=2000 node server.js

# 默契挑战:每轮 5 秒,揭晓停留 2 秒
MATCH_SECONDS=5 MATCH_REVEAL_SECONDS=2 node server.js
```

> 如果服务器跑在当前这台笔记本上,合盖或系统睡眠会让**整个服务暂停**,其他玩家也会掉线。需要长时间开桌时,可以用 `caffeinate` 阻止 macOS 睡眠:
>
> ```bash
> caffeinate -dimsu node server.js
> ```
>
> 或者把服务放到一台常开的电脑上。

## 让朋友连进来

**同一 WiFi**:启动后终端会打印局域网地址,例如 `http://192.168.5.13:3000`。

**公网临时隧道**(朋友不在同一网络):

```bash
# 安装(二选一)
brew install cloudflared
brew install ngrok/ngrok/ngrok

# 任选其一运行
cloudflared tunnel --url http://localhost:3000
ngrok http 3000
```

把命令生成的 `https://...` 链接发给朋友即可。隧道链接每次重启都会变。

## 注意

- **单房间**:所有连上服务器的人都在同一桌,暂时不支持多房间。
- **没有密码**:拿到链接的人都能加入。玩完记得关掉隧道,不要长期公开。
- **状态在内存**:重启服务器会清空牌桌,所有人需要重新入座。
- 玩家关闭页面后会先显示「离线」,**5 分钟内**重连可恢复;大厅里超过宽限期会自动移出,房主掉线会顺延给下一位在线玩家。房主也可以手动移出离线玩家。
- 断线时页面顶部会显示「连接中断,正在重连…」;浏览器会自动重连。名字会记在本地,重新入座时自动填好。
- 游戏中途刷新页面会保持身份(浏览器本地保存)。传声筒掉线保留席位,轮到他时 60 秒超时自动推进;默契挑战掉线本轮弃权,在线不足 2 人时本局结束。
- 传声筒投票按在线玩家结算,掉线的人不会阻塞;只要有人投了,也可以点「直接开奖」。
- 默契挑战每轮 40 秒;所有在线玩家交卷会立即揭晓,揭晓页停留 8 秒后自动进入下一轮。
